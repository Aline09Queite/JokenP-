✊ Jokenpô — Pedra, Papel e Tesoura

Projeto desenvolvido durante as aulas do DevClub, utilizando HTML, CSS e JavaScript, com o objetivo de criar um jogo de Jokenpô (Pedra, Papel e Tesoura) para jogar contra o computador.

🎮 Sobre o projeto

A proposta original do projeto foi utilizada como base para desenvolver o jogo, mas fiz algumas uma personalizações para deixar a aplicação com o meu toque pessoal.

A principal mudança foi na forma de apresentar o resultado da partida. Em vez de exibir apenas as mensagens tradicionais de “Ganhou”, “Perdeu” ou “Empatou”, utilizei emojis para representar cada resultado, tornando a experiência mais visual e divertida. 😄

🚀 Tecnologias utilizadas

* HTML
* CSS
* JavaScript

💡 O que pratiquei

* Manipulação do DOM
* Eventos e interações com o usuário
* Funções em JavaScript
* Estruturas condicionais
* Geração de escolhas aleatórias para o computador
* Alteração dinâmica de elementos da página
* Personalização de projetos a partir de uma proposta original

✨ Meu toque pessoal

Além de reproduzir o projeto apresentado nas aulas, aproveitei a oportunidade para experimentar e modificar algumas funcionalidades, colocando minha própria identidade no projeto.

Esse projeto foi mais uma etapa importante na minha prática com JavaScript e desenvolvimento Front-End, reforçando que aprender programação também é explorar, testar e transformar uma ideia em algo próprio. 💻🚀
